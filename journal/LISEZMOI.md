# Journal des exécutions

Un fichier par mois : `AAAA-MM.md`. Chaque exécution automatique d'un agent y
laisse une ligne.

C'est le « journal des exécutions » promis aux clients dans l'offre assistant.
Il tourne d'abord ici, au studio, avant d'être installé ailleurs.

## Format

```
## 2026-09-18

- 07:30 — brief-matin — lu : mail (12 non traités), agenda (3), pipeline (4 devis)
  → 2 brouillons dans sorties/, 1 relance proposée. Aucun envoi.
- 14:05 — carrousel — sujet « la fiche Google pèse plus lourd que le site »
  → 7 vues + légende dans sorties/carrousel/2026-09-18-fiche-google/. Non publié.
```

## Règles

- Une ligne par exécution, pas un récit.
- On note ce qui a été **lu**, ce qui a été **produit**, et ce qui a été
  **envoyé** — qui doit presque toujours être « rien ».
- Aucun contenu de mail, aucun nom de prospect, aucune donnée client : ce
  dossier est public. On note des volumes et des références, pas des contenus.
- Le journal se relit en fin de semaine pour voir ce qui tourne à vide.

Questions fréquentes

Application mobile sur mesure : vos questions.

Et pour voir le reste : les réalisations.

Quelle différence avec une appli des stores ?

Une application web installable s'ajoute à l'écran d'accueil depuis le navigateur, sans passer par l'App Store ni Google Play. Pas de validation, pas de commission, un seul code. En échange, elle n'apparaît pas dans les stores.

Ça marche vraiment sur iPhone ?

Oui : installation sur l'écran d'accueil, plein écran et hors ligne. Au Soleil et VIGIE s'installent de cette façon.

Combien coûte une application ?

Selon les écrans et les données à brancher. Un ordre de grandeur est donné dès le premier échange, et le devis écrit fixe le prix avant de commencer.

Combien de temps faut-il ?

Une première version à tester arrive en général en quelques semaines. Le délai de chaque étape est écrit dans le devis.

Peut-on la publier sur l'App Store plus tard ?

C'est possible en l'emballant dans une application native, mais c'est un autre chantier, que nous ne faisons pas nous-mêmes. La version web reste utile en attendant.

Qui héberge l'application ?

Vous, à votre nom : GitHub Pages gratuitement pour une appli simple, ou votre hébergeur. Les fichiers et le code vous appartiennent.

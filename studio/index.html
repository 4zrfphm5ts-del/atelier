Le suivi des outils sur mesure, concrètement

Chaque suivi comprend : la vérification quotidienne que chaque automatisation a tourné, le correctif quand une API ou un outil change, un point écrit à chaque période sans que vous le demandiez, une réponse sous 1 jour ouvré. Prix nets, TVA non applicable, art. 293 B du CGI. Les montants « à partir de » couvrent les cas simples ; les montants indicatifs sont confirmés par devis écrit avant de commencer. Ce que vous payez en direct, jamais via le studio : le nom de domaine (à votre nom), l'hébergement (gratuit sur GitHub Pages, ou votre hébergeur), les API d'IA si l'outil en utilise (facturées à l'usage, sur votre compte, avec la liste écrite de ce qui leur est envoyé). Les montants figurent dans chaque devis.

Vous possédez ce qui est livré pour vous. Je garde mon atelier.

Qui a les accès.

Ceux que vous me donnez, en lecture seule quand c'est possible, révocables par vous à tout moment. La liste des accès est écrite dans le devis et rendue à la passation.

Où vivent vos données.

Chez vous : votre stockage, votre caisse, votre machine. Je lis en place quand c'est possible ; toute copie de travail est listée dans le devis et effacée à la passation. Les éventuels appels à une API d'IA passent par votre compte, avec la liste écrite de ce qui leur est envoyé.

Ce que vous possédez.

Les sites, applications, tableaux de bord, classeurs et exports livrés pour vous, avec leur documentation. La notice décrit chaque étape, mais relancer la chaîne sans moi suppose de la reconstruire, et le devis le précise.

Si une API ou un outil change.

Pendant un suivi en cours, le correctif est inclus, dans le périmètre écrit au devis. Sans suivi, l'intervention est chiffrée avant, jamais subie.

Si on s'arrête.

À la fin de tout lot, sans pénalité. Ce qui est livré est payé et vous reste ; pour un site, une application ou un tableau de bord, la notice de passation permet à un autre développeur de reprendre.

Hébergement et coûts récurrents.

GitHub Pages, votre hébergeur ou votre machine, à votre nom. Domaine, hébergement et API d'IA sont payés par vous en direct ; les montants figurent dans chaque devis, séparés de ce que facture le studio.

FAQ

Les questions qu'on me pose avant de signer.

Combien de temps prend un site ?

Pour un site vitrine de l'atelier, quelques jours après validation du devis et réception de vos textes et photos. Pour une application ou un tableau de bord, le délai est écrit dans le devis, lot par lot. Pour un site de l'atelier, vous voyez la maquette avant de payer quoi que ce soit.

Comment se passe le paiement ?

Pour un site de l'atelier, vous voyez la maquette avant de payer quoi que ce soit. Pour les autres projets, chaque lot est testé avant d'en payer le solde ; l'éventuel acompte et sa part sont écrits dans le devis, avant de commencer. Prix nets, TVA non applicable, art. 293 B du CGI.

Est-ce que je dépends de vous ensuite ?

Non pour les sites, applications, classeurs et tableaux de bord livrés : vous recevez les fichiers, les accès et une notice de deux pages qui explique comment ça tourne et quoi faire si ça s'arrête. Un autre développeur peut reprendre avec cette notice : c'est un critère de validation écrit, vérifié avant la passation. Pour un système qui s'appuie sur l'outillage du studio, comme un moteur de campagnes, vous gardez vos données, vos comptes et vos résultats ; relancer la chaîne sans moi suppose de la reconstruire, et le devis le dit.

Y a-t-il un abonnement ?

Aucun abonnement n'est obligatoire. Les sites de l'atelier tiennent dans un fichier hébergé à votre nom. Si vous préférez déléguer l'hébergement, le nom de domaine et les retouches courantes, l'option tranquillité est à 29 € par mois, résiliable quand vous voulez. Pour les tableaux de bord et les automatisations, un suivi mensuel ou trimestriel est proposé sur devis.

Que veut dire « IA appliquée » ?

Des assistants et des automatisations branchés sur vos outils (mail, agenda, CRM, classeurs, caisse) pour lire, trier, rédiger et prévenir, avec des garde-fous écrits : lecture seule quand c'est possible, validation humaine avant toute écriture. Pas de modèle entraîné sur mesure, pas de recherche : de l'intégration qui rend service tous les jours.

Où vont mes données ?

Elles restent chez vous : votre stockage, votre caisse, votre machine. Je les lis en place, en lecture seule quand c'est possible ; toute copie de travail est listée dans le devis et effacée à la passation. Si un outil utilise une API d'IA, c'est sur votre compte, avec la liste écrite de ce qui lui est envoyé et de ce qui ne l'est jamais ; vous pouvez la couper à tout moment. Les sites livrés ne posent aucun cookie.

Signez-vous un accord de confidentialité ? Et le RGPD ?

Oui, avant tout accès à vos données si vous le souhaitez. Si le travail touche des données personnelles, un accord de sous-traitance au sens du RGPD est signé avant tout accès. La liste des accès est écrite dans le devis et rendue à la passation, et aucun nom de client n'est cité sur ce site sans son accord.

Vous êtes seul, et si vous n'êtes pas là ?

Je suis entrepreneur individuel et je dirige le studio. Ce qui le rend solide : des livrables autonomes qui tournent sans moi, une notice de passation par projet, un réseau de partenaires (design, rédaction, photo, développement) activés selon le projet, et des agents IA et automatisations qui tiennent le suivi. Je ne promets pas d'astreinte de nuit ; je promets une réponse sous un jour ouvré.

Pouvez-vous reprendre un outil existant ?

Oui, c'est même le cas le plus fréquent : un site vieillissant, un classeur devenu ingérable, un CRM à nettoyer, une automatisation cassée. Je commence par le devis écrit et gratuit, qui dit ce qui se garde, ce qui se remplace et ce que ça coûte ; si le chantier le justifie, il propose un diagnostic facturé, chiffré d'avance.

Combien ça coûte, vraiment ?

Les prix de l'atelier web sont affichés : site dès 690 €, menu QR dès 290 €, fiche Google 190 €, pack dès 990 €. Pour le conseil et les outils sur mesure, le devis est écrit avant de commencer et fixé pour tout le projet ; deux offres portent un montant indicatif. Les coûts récurrents (domaine, hébergement, API d'IA) sont payés par vous en direct et détaillés dans le devis. Prix nets, TVA non applicable, art. 293 B du CGI.

Vous travaillez hors de Lille, et en anglais ?

Oui. Le studio est à Lille et travaille avec Paris, Bruxelles et Zurich, à distance comme sur site. Français natif, anglais professionnel : les livrables et les échanges peuvent être en anglais.

Qu'est-ce que vous ne faites pas ?

Pas d'application native publiée sur les stores, pas d'astreinte de nuit ni de week-end, pas de modèle d'IA entraîné sur mesure, pas de gestion de vos campagnes publicitaires payantes, pas de site sous CMS à abonnement. Si votre besoin est là, je vous le dis au premier appel et je vous oriente.

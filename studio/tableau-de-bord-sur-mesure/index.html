Questions fréquentes

Tableau de bord sur mesure : vos questions.

Et pour voir le reste : les réalisations.

Combien coûte un tableau de bord sur mesure ?

Cela dépend du nombre de sources et d'écrans. Un ordre de grandeur est donné dès le premier échange, puis le devis écrit fixe le prix avant de commencer. Il n'y a pas de licence mensuelle par utilisateur.

Quelles sources pouvez-vous brancher ?

Les exports ou les API de votre caisse, de votre CRM, de votre banque ou de votre logiciel comptable, et vos fichiers Excel ou Google Sheets. Si une source n'a ni export ni API, je vous le dis dans le devis.

Faut-il changer de logiciel ?

Non. Le tableau de bord lit ce que vous avez déjà, en lecture seule quand c'est possible.

Où sont stockées mes données ?

Chez vous : votre hébergement, votre espace de stockage. Toute copie de travail est listée dans le devis et effacée à la livraison.

Combien de temps pour le mettre en place ?

Souvent deux à six semaines selon les sources, avec une première version à tester rapidement. Le délai est écrit dans le devis, étape par étape.

Et si un outil change son export ?

Le contrôle quotidien le détecte et vous prévient. Pendant un suivi, le correctif est inclus ; sans suivi, il est chiffré avant d'être fait.
